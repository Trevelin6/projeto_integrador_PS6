Neste projeto utilizaremos do framework Spring, com as coleções:

- Spring Web: para criar a Rest API e os endpoints
- H2 DATABASE: o banco de dados local utilizado para armazenar os dados
- Validation: utilizado para barrar dados inválidos/formatados incorretamente
- Spring Data JPA: auxilia no desenvolvimento e segurança com o uso do banco de dados
